# Produto selado — o que falta confirmar no Cardmarket

**27/09/2026.** O lado do CardTrader está fechado: varri as 13 categorias do jogo 22
e as 17 expansões pela API (210 produtos não-single, 85 nas 6 categorias de selado).
Não há um único produto selado no CardTrader que a app não conheça.

O Cardmarket não dá para automatizar: responde com o desafio do Cloudflare
(«Verifique que você é humano») tanto ao pedido directo como ao browser do Claude,
e a API deles está fechada a novos pedidos de acesso
(«Currently, we are not accepting applications for access to the Cardmarket API»).
Completar o desafio é coisa que eu não faço — tem de ser clicado por ti.

**Duas formas de despachar isto:**

1. **Uma só vez, e fica resolvido para sempre:** no Claude do PC, abre o painel do
   browser (Ctrl+Shift+B), vai a `cardmarket.com` e clica na caixa de verificação.
   O perfil desse browser guarda-a, e a partir daí eu leio o Cardmarket sozinho —
   esta lista e as próximas.
2. **À mão, agora:** os links abaixo abrem a pesquisa do Cardmarket já preenchida.
